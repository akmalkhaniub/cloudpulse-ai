        MANDATORY "SHAPE" TRACK DELIVERABLE
        
Structured Product Feedback for Amazon Developer & Bedrock Engineering Teams

        
Actionable friction points, schema observations, and feature requests gathered while building CloudPulse AI across Alexa+ MCP (`2026-07-28`), Amazon Bee, Fire TV, and Amazon Bedrock Converse API.

      


      

        

          

            
            1. Alexa+ MCP (2026-07-28) & Bedrock Schema Alignment
          

          

            Friction: Mapping MCP `2026-07-28` JSON Schema 2020-12 `inputSchema` / `outputSchema` to Bedrock Converse `toolSpec.inputSchema.json` requires manual wrapper conversion.


            Recommendation: Provide a native `@amazon-alexa/mcp-bedrock-bridge` utility that automatically translates MCP `2026-07-28` `tools/list` descriptors into Bedrock `ConverseCommand` `toolConfig` definitions and Alexa+ voice slot types.
          

        

        

          

            
            2. Bedrock Converse Model ID Portability
          

          

            Friction: Cross-region inference profile prefixes (`us.anthropic...`) vs direct foundation model IDs (`amazon.nova-pro-v1:0`) behave differently depending on account marketplace entitlements.


            Recommendation: Add a `ConverseCapabilities` discovery call in `@aws-sdk/client-bedrock-runtime` that returns the account's currently callable tool-use models without trial-and-error invocation.
          

        

        

          

            
            3. Amazon Bee Wearable Structured Webhook Events
          

          

            Friction: Ambient meeting transcripts from wearables arrive as unstructured dialogue turns without speaker role tagging or technical entity extraction.


            Recommendation: Expose an MCP-compatible `bee://memories/action-items` resource stream that emits speaker-attributed technical intents directly to registered Alexa+ MCP servers.
          

        

        

          

            
            4. Fire TV Vega OS / Web App D-Pad Focus Standard
          

          

            Friction: Building 10-foot engineering wallboards for Fire TV requires custom keyCode/spatial navigation handling across web and native views.


            Recommendation: Provide a lightweight `@amazon-devices/vega-web-spatial-nav` polyfill so web-based MCP visual cards automatically support Fire TV directional remote controls.
