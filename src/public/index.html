        Developer Experience Feedback
        
Recommendations for Amazon Product & Platform Teams

        
Friction points and architectural opportunities identified while building across Alexa+ MCP, Bedrock Converse, Bee Wearable, and Fire TV.

      


      

        

          

            1
            Alexa+ MCP & Bedrock Converse Schema Alignment
          

          

            Friction: Mapping MCP JSON Schema 2020-12 descriptors into Bedrock Converse toolSpec.inputSchema.json requires custom runtime adapters.

            Recommendation: Ship an official @amazon-alexa/mcp-bedrock-bridge library to serialize MCP tools directly into Converse parameters.
          

        


        

          

            2
            Bedrock Tool-Use Model Introspection
          

          

            Friction: Foundation models fail differently if the caller's IAM principal lacks tool-use entitlements in a specific region.

            Recommendation: Add a listConverseReadyModels() API filter in the Bedrock SDK to discover callable tool-use models cleanly.
          

        


        

          

            3
            Bee Wearable Structured Webhook Dispatches
          

          

            Friction: Wearable meeting transcripts stream unformatted conversational audio without infrastructure entity tagging.

            Recommendation: Allow Bee apps to register domain entity extractors that emit signed JSON-RPC events directly to self-hosted MCP endpoints.
          

        


        

          

            4
            Fire TV Web App Spatial Navigation Standard
          

          

            Friction: Creating 10-foot NOC interfaces for Fire TV requires custom key-down spatial focus handlers.

            Recommendation: Release an official web spatial navigation polyfill for Fire TV / Vega OS browsers.
