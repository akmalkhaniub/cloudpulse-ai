# Build, Ship, Shape: Amazon Developer Hackathon

- **Official Challenge URL:** [https://amazonappdev2026.devpost.com/](https://amazonappdev2026.devpost.com/)
- **Organizer:** Amazon
- **Host Platform:** Devpost (Managed by Devpost)
- **Prize Pool:** $138,000 USD (Cash awards)
- **Submission Dates:** August 31, 2026 – October 23, 2026
- **Format:** Online / Global
- **Primary Themes:** Machine Learning / AI, Developer Tools & Productivity, Open Ended Cloud Systems

---

## 1. Hackathon Objective & Problem Statement
Amazon Developer Hackathon challenges engineers and architects to build cutting-edge applications, services, or developer tools that solve real productivity, cloud orchestration, or customer-facing challenges using modern cloud architectures, generative AI, and resilient distributed services.

### Judging Criteria
1. **Technological Implementation (25%):** Quality of software engineering, cloud architecture, and appropriate use of scalable services.
2. **Impact & Utility (25%):** How well does the tool or platform address a high-friction problem for developers or end-users?
3. **Innovation & Originality (25%):** Novel approach, unique capability, or significant architectural advancement over existing solutions.
4. **User Experience & Polish (25%):** Interface responsiveness, comprehensive documentation, and seamless developer onboarding.

---

## 2. Selected Project Concept: CloudPulse AI (Autonomous Cloud Architecture & Cost Sentinel)
An intelligent, proactive cloud developer copilot that continuously analyzes infrastructure-as-code (Terraform, CDK), provides real-time architectural compliance, pinpoints cost anomalies, and generates automated self-healing PRs with LLM-backed verification.
